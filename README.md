# AI聚合比价空间

把散布在各个卡网（发卡平台）和 AI 代充聚合站的 AI 订阅 / 账号商品（ChatGPT、Claude、Gemini、Grok、Cursor 等的代充、成品号、卡密、车位）聚合到一处，按关键词、平台、店铺、价格、库存快速比价。

只做信息聚合，不卖货、不下单、不登录任何账号。

## 在线使用

直接打开 `index.html` 即可（静态页，无需构建、无需后端）。也可以用 GitHub Pages 发布本仓库，`index.html` 就是入口。

## 功能

关键词搜索（搜商品名）；按平台 / 来源 / 分类 / 店铺筛选；只看有货开关；价格排序（低→高 / 高→低）与价格区间；每页 100 件分页，全部筛选可叠加。商品卡显示平台与来源标记、库存状态（有货 N 件 / 已缺货 / 库存未公开），「去购买」按钮与店铺名链接到原站。

## 样式

前端样式按 [taste skill](https://github.com/Leonxlnx/taste-skill)（design-taste-frontend v2.5.1）deal 的方向做：trade ai、page software，配色 cool-grey-cobalt（底 #eef0f3、面 #e2e5ea、墨 #0b0c0e、强调钴蓝 #1f2de6），字体 Host Grotesk + JetBrains Mono（价格与数字用等宽字体），soft 圆角。

## 更新数据

重新采集各源数据后替换 `data.json`，并用同一份数据重新导出页面替换 `index.html`。Muse 空间版的数据是独立文件、页面加载时以 `no-store` 拉取；本仓库的 `index.html` 是自包含快照（数据内嵌），两者内容一致、形态不同。
