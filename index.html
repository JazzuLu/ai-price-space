数据来源与口径说明

  • CardNav（cardnav.xyz）：公开商品快照（批量 JSON 接口），按 autoCategory 与标题规则归类。
  • BiWu.Ai：标准商品页全渠道报价表。
  • AI价网（aiprice.club）：跨平台报价数据（CC BY 4.0），其 md 层每类只含在售最便宜 50 家，链接指向 AI价网分类/店铺页。
  • PriceAI（priceai.cc）：公开快照报价行（仅保留更新鲜报价）。
  • 水獭（shuita.xyz）：派生报价行（兜底缓存，时效弱于其他源）。

库存口径：数字仅在源站提供数量时代表库存件数；部分来源仅提供「有货 / 缺货」标记；未公开库存不计入有货最低价。去重规则：先按同商品直链去重（保留同页不同规格），再做严格跨源同店同标题同价去重；wzyp / 云猫按平台店铺 ID 区分同名异店。本页支持 URL 参数同步（如 ?platform=OpenAI、?product=chatgpt-pro-100）与浏览器原生返回。
